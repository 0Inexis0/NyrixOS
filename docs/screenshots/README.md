# Screenshots

## Current desktop — 2026-11-18

These are direct QEMU framebuffer captures of the running, disk-installed
NyrixOS development VM, converted losslessly from PPM to PNG at 1280×800.
No generated UI, compositing, retouching or simulated values are used.
The UI is shown in German; English is also supported.

- [Desktop](desktop-current.png): wallpaper and floating bar.
- [Settings](settings-current.png): profile, categories and Network & Bluetooth.
- [Dynamic Island](island-current.png): expanded local calendar.
- [Control center](control-center-current.png): radio switches and sliders.

The VM has no Wi-Fi/Bluetooth adapter or backlight device, so their unavailable
states are genuine. The calendar is local, not a connected calendar account.
These images document the current development desktop, not a newly built ISO.
